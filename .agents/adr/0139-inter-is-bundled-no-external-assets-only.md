# 139. Inter is bundled, and "no web fonts and no external assets" narrows to "no external assets"

2026-10-29, relates to 62, 70, 95, 137, 138

**Context:** the board's own rule, "no web fonts and no external assets", lived in the stylesheet's header and QUIRKS.md rather than in an entry: every page and its saved copy had to open with the network off, so the board drew in the system font stack. The person picked Inter for the denser look of 137 and 138; the recommendation had been no font. **Decision:** the rule narrows to "no external assets". Inter (SIL OFL 1.1, Latin subset, weights 400, 500, 600 and 700, vendored in `src/vendor/inter/` with its licence) is inlined in the stylesheet as `data:font/woff2;base64,` `@font-face` rules, so served pages and saved copies load it from their own bytes with no request, under the existing `font-src data:`. `body` opens on Inter with the system stack after it, so a failed load reads as before. Any face pointing at a host, a path or a sibling file is refused by `test/check-pure.mjs`. **Consequences:** about 97 KB raw (129 KB base64) on the shared stylesheet, and inlined into the home page's HTML on every load; capped at 120 KB raw by `test/check-pure.mjs`.
