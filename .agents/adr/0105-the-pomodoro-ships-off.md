# 105. The pomodoro ships off

2026-08-12 · narrows 103; relates to 68, 84, 90

**Context:** ADR 103 made the pomodoro optional but left it on by default, so a fresh install still grew a timer, its settings sections and a tomato in the menu bar before anyone asked for one — scope surprise in the first five minutes of a tool whose pitch is a review surface. **Decision:** `enabled` defaults to `false` at every site that holds a default — `DEFAULT_SETTINGS`, the menu-bar client's missing-key fallback, the widget's own parameter — so a fresh install renders no pomodoro anywhere and the status item leads with what it exists for, the waiting-boards list. A settings document or API response missing the key now reads as off: a missing key means a fresh document, and 103's pre-existing-document upgrade path is dropped as having had no users. **Consequences:** the timer exists only for a reader who flips the Master switch in the settings panel; the session-start hook's `ensure` is refused until then, hook installed or not; 103's off-is-absence semantics are untouched — only the starting point moves, and the Board glyph is now the item's first face rather than its fallback.
