# 66. The owed-round dot takes a different hue in each theme

2026-08-09 · narrows 30

**Context:** every *waiting on you* surface spends one amber, but the pager's owed dot sits beside the current page's own chip, and neither palette serves both readings — dark's amber crowds the panel it sits on, and light's `--warning` is the `#805300` brown entry 30 already rules out for the tab mark. **Decision:** the dot reads `--owed-dot`, defined per palette — the accent in dark, DARK's amber named explicitly in light — rather than one token across both. **Consequences:** *waiting on you* is no longer one hue product-wide, so a reader comparing the dot against the tab mark across themes finds them deliberately different, and a future status colour cannot assume the convention holds without checking.
